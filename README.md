# InManage Backend Test

PHP backend assignment using PHP, MySQL, PDO, cURL and OOP.

## Features

- MySQL database connection using PDO
- Reusable Database class
- SELECT, INSERT, UPDATE and DELETE operations
- Users import from JSONPlaceholder
- Posts import from JSONPlaceholder
- API requests using cURL
- Default avatar download using PHP
- Active users and posts feed
- Birthday users with their latest post
- Posts count grouped by hour
- Database ER diagram

## Requirements

- PHP 8+
- MySQL 8+
- PHP extensions:
  - PDO MySQL
  - cURL
